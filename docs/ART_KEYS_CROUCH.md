# Crouch art keys (Art -> Engine / Render / Gameplay)

Dedicated `crouch_idle` and `crouch_walk` animations for every live v1 doll layer (players and AI humans):
body, clothing, hair, hats, face, eyes, hands, accessories, held-item hand anchors, and every customization
option, at the same parity as the `ride_*` anims (`a775f75c`). ADR-241 chains `crouch_idle` → `idle` and
`crouch_walk` → `crouch_idle` → `walk` → `idle`. ADR-244 is the crouch stance (toggle, walk ×0.6, no sprint).

Generated by `assets/customization/tools/crouch_merge.py` (rig pose in `rig.py`, same layer renderer as
idle/walk). Append-only: existing cells are untouched. Pages are streamed like `cz_ride_*` (wear pool,
never prefetched or warmed at boot; the renderer falls back to idle while a crouch page is paging in).

## Pose

A lower, bent-knee, slightly hunched sneaky stance. Walk is a short-stride creeping tiptoe gait (weight
transfers, opposite arm swing, foot on the ball). Every frame is freshly painted: no reused standing
cells, no tints. Cute cartoony solid cel (flat fills, one hard shade, a hard highlight, binary alpha,
bold slightly-dark outlines). Masks and bandanas use the same facing logic as idle, so they read
correctly from every direction.

Frame counts are the minimum smooth loops that still read (Pages dist budget, ADR-332–334): 2-frame
idle bob/blink, 4-frame walk cycle. Not a quality cut — a shorter cycle of unique posed frames.

## Anims, facings, timing

| anim | frames | fps | ms/frame | loop | looks like |
|---|---|---|---|---|---|
| `crouch_idle` | 2 | 4 | 250 | yes | planted sneak, breathing bob, blink on frame 1 |
| `crouch_walk` | 4 | 8 | 125 | yes | creeping tiptoe, 0.5 s stride |

8 facings, the same index order as the character dolls (engine dir 0..7 = E, SE, S, SW, W, NW, N, NE;
in the iso view: 0 front-right 3/4, 1 front, 2 front-left 3/4, 3 left side, 4 back-left 3/4, 5 back,
6 back-right 3/4, 7 right side).

Layout: **rect** dirFrames (`DirFrameJson.rect`) on skyline-packed pages, index `i = frame * 8 + facing`;
`frames` = `[0..n-1]`, `dirStride` = n. Cells are trimmed per frame (1 px wear gutter, 2 px body border
plus the feet pivot and the ADR-128 head reference). Fully transparent cells share one 1×1 clear rect
per page. Binary alpha, 0/255 tintmasks.

## Pivot and anchors

* 1x frame space is 48×80; feet pivot is `(24, 74)` → default sprite anchor `(0.5, 0.925)`. Each
  dirFrame carries its own `anchor` relative to the trimmed rect, so the feet stay planted.
* Body `frameMeta["df:<i>"].anchors`:
  * `head` `{x: 0, y: -29.65}` — ADR-128 neck reference (sprite `attach.head` is `{x: 0, y: -26.65}`;
    head-group layers lift by `head - attach.head` = `(0, -3)`). Pose change is baked into every layer's
    pixels, same as sit/swim/idle.
  * `handR` / `handL` — held-item sockets, pivot-relative 1x px, with `angle`, `len`, `behind`.

## Pages

`cz_crouch_<slot>_<n>` (slot = body, top, bottom, shoes, hair, hat, face, eyes, hands, accessory).
PNG + KTX2 at 1x and @2x colour; 1x tintmask PNG + KTX2 (the 2x tintmask is a nearest upscale of a
0/255 mask, so it is omitted to keep the Pages artifact lean; the client falls back to the 1x mask).
Every page is ≤ 1024 px on the long side at 1x.

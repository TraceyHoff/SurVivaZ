# Waterfall art keys (Art → Engine / Render)

Dedicated, unique waterfall tiles for ADR-386 (elevated-lake spillways). Generated by
`packages/assets/pack/nature/src/artpass_waterfall.py` (add-only; does not run `ground_pack.py`).
One tight page `gt_waterfall` is merged into `packages/assets/pack/manifest.json`. Re-run the
packer, then `pnpm --filter @engine/assets lock:ids:pack`. `ground_pack.py` retains `gt_waterfall*`
so a later ground rebuild will not wipe them.

Style: the same teal family as `gt_water` (WCOL), but original marks — downward-moving streak
columns, a foam curl at the lip, an impact foam shelf and soft mist at the pool. Not a recolor or
reuse of any `gt_water` / `gt_water_shallow` frame. Waterfall faces do not ice over in winter
(ADR-386), so there is no seasonal twin. Soft alpha is used only for mist / spray (the allowed
exception); water and foam are solid cel with binary alpha.

## Page

| atlas | 1x | @2x | residency |
|---|---|---|---|
| `gt_waterfall` | ≤1024 (currently 308×312) | exact 2× (616×624) | `gt_` prefix: kept hot at 1x with the other ground pages. One small page. |

PNG + KTX2 at both scales. Cells are shelf-packed, trimmed to the opaque bbox plus 2 px bleed.
Wire frames with `AssetRegistry.dirFrame()` (each anim carries `dirFrames[].rect` + `anchor`).
`frame()` would resolve the whole page and is the wrong entry point.

Paint box is a 64×64 1x ground cell (32 px diamond + 32 px skirt for a 2-level face). The
**anchor is the diamond centre**, the same world point as `gt_water` (`(0.5, 18/52)` on a 68×52
cell). On a trimmed rect the anchor may sit outside the pixels (allowed; `DIRFRAME_ANCHOR_SLACK`
is 8). Overlay a lip or pool on the source/dest water top, and sit a sheet on the cliff face of
the source tile (z-order: dest water + pool, then source top + lip, then the sheet, or the mesh
face the sheet replaces).

## Keys (unique art)

6 looping frames, 8 fps (125 ms/frame, 750 ms loop), `animations.idle`, `loop: true`,
`directions: 1`. Category `tile`. Placeholder `gt_water`.

Facing names match the ADR-386 cliff / waterfall flags in `packages/render/src/tilemap.ts`:

| suffix | engine flag | normal | default iso (view 0) |
|---|---|---|---|
| `px` | `CLIFF_PX` = 2, `WATERFALL_PX` = 6 | +x | camera-front, lower-right |
| `nx` | `CLIFF_NX` = 4, `WATERFALL_NX` = 8 | −x | far side, upper-left |

| key | shape | what |
|---|---|---|
| `gt_waterfall_lip_px` | lip | water curling over the source tile's +x (SE) edge |
| `gt_waterfall_lip_nx` | lip | same, over the source tile's −x (NW) edge |
| `gt_waterfall_sheet_1_px` | 1-level sheet (16 px) | downward-streak curtain on the +x face |
| `gt_waterfall_sheet_1_nx` | 1-level sheet (16 px) | downward-streak curtain on the −x face |
| `gt_waterfall_sheet_2_px` | 2-level sheet (32 px) | the same curtain, two height levels tall |
| `gt_waterfall_sheet_2_nx` | 2-level sheet (32 px) | far-side 2-level curtain |
| `gt_waterfall_pool_px` | splash / foam pool | impact foam + mist on the **destination** tile of a `px` fall (foam along the dest's −x / NW edge) |
| `gt_waterfall_pool_nx` | splash / foam pool | impact foam + mist for an `nx` fall (foam along the dest's +x / SE edge) |

## Flip map (not packed)

The sprite renderer already supports `FrameRef.flipX`. In 2:1 iso, the other two facings are
horizontal mirrors of the two we ship — packing them would double the page for no unique art.
Draw these with `flipX` on the named source:

| draw this | as | engine flag | normal | default iso (view 0) |
|---|---|---|---|---|
| `gt_waterfall_lip_px` + flipX | lip `py` | `CLIFF_PY` = 3, `WATERFALL_PY` = 7 | +y | camera-front, lower-left |
| `gt_waterfall_lip_nx` + flipX | lip `ny` | `CLIFF_NY` = 5, `WATERFALL_NY` = 9 | −y | far side, upper-right |
| `gt_waterfall_sheet_1_px` + flipX | 1-level sheet `py` | same | +y | lower-left face |
| `gt_waterfall_sheet_1_nx` + flipX | 1-level sheet `ny` | same | −y | upper-right face |
| `gt_waterfall_sheet_2_px` + flipX | 2-level sheet `py` | same | +y | lower-left face |
| `gt_waterfall_sheet_2_nx` + flipX | 2-level sheet `ny` | same | −y | upper-right face |
| `gt_waterfall_pool_px` + flipX | pool `py` | — | dest of a +y fall (foam on dest's −y / NE edge) |
| `gt_waterfall_pool_nx` + flipX | pool `ny` | — | dest of a −y fall (foam on dest's +y / SW edge) |

When the camera quarter-turns (ADR-253), the same four world normals keep these keys; only which
ones are camera-front vs far changes (`cliffShade`).

## ADR-386 case → key

Spillway encoding (`packages/world/src/waterFeatures.ts`, ADR-386): `tiles[0] = L−1` (breach, still
the lake rim), `tiles[1] = L−3` (the 2-level falls), then −1 per tile down to a floor of 1, running
flat to the sea. Every spillway has ≥ 2 tiles, so the 2-level drop always exists. The engine today
marks a **waterfall face** only when a water tile drops `WATERFALL_MIN_DROP` (= 2) or more to a
neighbour that exists (`cliffFlagFor`); 1-level ledges stay ordinary stream ledges (skirt kept).
The 1-level sheet keys are shipped so the cascade after `tiles[1]` can be wired without a second
art pass.

| ADR-386 case | art |
|---|---|
| Breach / source top, water curling over the drop edge | `gt_waterfall_lip_<dir>` on the **upper** tile |
| `tiles[1]` — the 2-level falls (drop = 2, flag 6..9) | `gt_waterfall_sheet_2_<dir>` on that tile's falling face |
| Each later channel step, drop = 1 (currently a plain cliff / skirt; art is ready) | `gt_waterfall_sheet_1_<dir>` |
| Drop > 2 (junction face, rim touching level-0 water — queued follow-up in the ADR) | use `sheet_2` (the steepest dedicated sheet); do not stretch. A taller drop can stack `sheet_2` + `sheet_1` if needed. |
| 1-level ledge that is *not* part of a spillway cascade | optional `sheet_1`; the current renderer will not flag it as a waterfall |
| Destination / base of a fall (the lower neighbour) | `gt_waterfall_pool_<dir>` on the **lower** tile, same `<dir>` as the sheet that lands on it |
| Closed lake (no spillway, ~52% of sited lakes) | no waterfall art |
| Land cliffs, missing neighbour (view edge / unloaded), drop to `NO_TILE_HEIGHT` | never a waterfall (ADR-386); do not use these keys |
| Winter / ice / season tint | do not ice the falls (the flat water still ices). No `_winter` / `_fall` / `_spring` twins. |

`<dir>` is `px` / `nx` (unique) or `py` / `ny` (flipX of `px` / `nx`), from the face normal of the drop.

## Audio

No waterfall SFX is shipped. The audio bank has `amb.water.shore`, `footstep.water`,
`mount.hoof.water` and `farm.water`, but no falls-loop or splash hook, and ADR-386 noted there
are no sound hooks in gameplay yet. A later `amb.water.falls` loop + `sfx.waterfall.splash`
one-shot would be the obvious place; it was left out so the Pages dist stays lean.
